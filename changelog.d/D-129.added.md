- **O executor cuida dos PRs do Dependabot: `guia deps` (D-129, épico E-005, R11).** Inventaria os PRs abertos do bot e os tria — bump é só manifesto/lockfile ou só linhas `uses:` de workflow; o resto vai para a `pr-audit`; rótulo `security` marca prioridade. `deps --now` cria a demanda do lote (uma por vez), e o executor a cria sozinho quando a fila esvazia (`trigger: on-idle`). Quem junta as versões é a skill `pr-bump`, num chat; integrado o lote, o executor fecha cada PR do bot incorporado com link para ele. PR do bot nunca entra na fila normal nem recebe `update-branch`. Testes em `tests/test_dependabot.py`.
