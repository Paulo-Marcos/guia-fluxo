- **`init --locks adicoes|testes|nenhum`: perfil de travas no setup.** Antes o `init` sempre deployava a trava global `adicoes-exigem-autorizacao` (todo arquivo novo exige `[unlock:...]`). Registry existente é preservado, com aviso, salvo `--force`. Este repositório passa a usar `testes-sao-contrato`. Testes em `tests/test_init_lock_profiles.py` (D-158).
